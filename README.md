# Music Player

## Description

A web-based music player that can play, pause, skip, and adjust volume of songs. Displays song info, cover art, and a progress bar, with smooth animations and looping playlist functionality.

## Features

- Play / Pause songs
- Skip to next or previous song
- Volume control and mute/unmute
- Draggable and clickable song progress bar synced with audio.
- Playlist loops automatically
- Display artist name, song title, and cover image
